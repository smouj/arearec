# Voryda Rec brand

Voryda Rec is the region-recording utility in the Voryda family. Its approved icon pairs an ivory capture frame with a luminous red record button on the shared dark rounded-square tile.

## Core assets

| Asset | Purpose |
| --- | --- |
| `assets/voryda-rec.png` | Approved 1254×1254 RGBA master icon from the final icon pack. |
| `assets/logo.png` / `assets/logo-dark.png` | README-compatible paths containing the same approved icon for both color schemes. |
| `assets/mark.png` | Windows icon source; kept identical to the approved master. |
| `assets/AreaRec.ico` | Multi-resolution Windows executable, window and shortcut icon. |
| `tools/BuildAppIcon.ps1` | Rebuilds the Windows icon at 256, 128, 64, 48, 32, 24 and 16 pixels, preserving transparency. |
| `assets/social-banner.png` / `assets/social-banner.svg` | Optional legacy social-preview artwork; not embedded in the README. |

| Token | Value |
